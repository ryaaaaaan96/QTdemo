# 架构约定

- src/app：启动流程、应用信息、依赖组装。
- src/ui：窗口、对话框、自定义控件和 .ui；只处理交互与展示。
- src/core：可独立测试的业务规则，禁止依赖 QWidget。
- 后续按需新增 src/services：文件、网络、数据库、设备等外部访问；由 UI 调用服务，服务组织业务。
- resources：图标、样式、翻译，通过 Qt Resource System 打包。
- tests：业务单元测试和启动冒烟检查；随真实功能扩充。
- cmake / packaging / scripts：构建规则、安装规则、开发命令。
- build / stage / dist：编译中间文件、部署目录、发行包，不进入版本控制。

界面耗时操作移到工作线程，通过 signal/slot 回到 UI 线程。配置使用 QSettings，日志与用户数据使用 QStandardPaths，避免写入安装目录。网络、数据库和设备协议按真实需求添加 Qt 模块，避免预先引入空泛框架。

正式产品还需要：产品名称与版本规则、应用和安装器图标、错误处理与日志、配置迁移、业务测试、第三方组件清单和对应许可材料、安装升级策略、Windows 代码签名及干净机器上的安装/卸载验证。当前产物是工程模板演示包。
